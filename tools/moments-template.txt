# ملف لحظات الفيديو. سطر لكل لحظة بهالشكل:  الوقت | الطلب
# الوقت: MM:SS أو HH:MM:SS، مثلاً 00:23 أو 01:02:05. الأرقام العربية مقبولة.
# الطلب: كلام حر. كل اللي بعد أول | هو الطلب.
# Claude بيفهم وبيشرح أول، وبيسألك قبل أي تطبيق، إلا إذا طلبك حكى غير هيك.
# إذا الطلب فاضي، Claude بيوصف شو بتبيّن اللقطة.
# الأسطر اللي بتبلّش بـ # ما بتنقرأ. احفظ الملف UTF-8.
# مثال (شيل # من أول السطر عشان ينقرأ):
# 00:23 | بتقدر تطبّق هاد البرنامج عندي؟
# 01:10 | اشرحلي بس شو هاد، بدون تطبيق
# 01:45 |
